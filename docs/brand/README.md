# VaaniFlow brand

**Mark:** five voice bars stepping down into a "V". The lowest bar is teal: that's the AI.
The same mark is used on the website, dashboard, docs, Android launcher icon (adaptive and
Material You themed) and notification icon.

| File | Use |
|---|---|
| `logo.svg` | App icon / favicon (indigo tile, white bars, teal AI bar) |
| `logo-mono.svg` | Single colour (`currentColor`) for print, dark or light UI |
| `vaaniflow-icon-512.png` | Google Play store icon |
| `vaaniflow-icon-1024.png`, `-192.png` | Social, PWA |

**Colours:** Indigo `#5B3FF5` (tile `#7B6BFF → #4527E8`), AI teal `#5EEAD4` / `#14B8A6`, ink `#0A0A0B`.
**Type (web):** Geist and Geist Mono. The Android app uses the phone's own font.
